Lux-Shot

Built with:

Deployed with:

Lux-Shot is an image server made to replaces unreliable services like Lightshot and Gyazo. The server is Flask based providing a minimal UI with username/password authentication. Images are uploaded to an API endpoint using an API key for authentication. There are three client apps: Android, Python, and Go. The Python client has been tested on Windows only. The Go client has been compiled and tested on both Windows and Linux.
